class GameMode.Scene реализовал: Влад
    это класс кторым упрвляет GameMode.GameMode он хранит в себе всю информацию о сцене
    каждая сцена имеет свое имя и доступ к кажой сцене имеется по имени
    каждая сцена хранит в себе JPanel который и отрисовывется для сложных сцен, можно реализовывать свой класс наследик класса JPanel и установить в сцену с помощю метода
    setScene()
    также к каждой сцене можно привязать свой GameMode.HUD которорый будет отображатся вместе с сценой
    у сцены есть интерфейс GameMode.Drawable(читать раздел interface GameMode.Drawable)
    сцены мужно созжать в классе GameMode.GameMode с помощью метода createScene(название сцены)
    конструктор класса GameMode.Scene принемает имя сцены, имя это идефекатор сцены
    каждая сена хранит в себе поля
    JPanel scenPanel - панель сцены
    String name = имя
    ArrayList<String> hudSceneNames - список SceneHUD а именно их индеффекаторы котрые будут отображаться вместе с сценами
    ArrayList<GameMode.Drawable> drawObjects - обекты к которым подключен интерфейс GameMode.Drawable (читать раздел interface GameMode.Drawable)

        этот интерфейс предназначен для классов в которые мы хотим рисвоать обекты
        что бы нарисовать какой либо объект нам нужно имплементировать этот интерфейс в том классе где нам надо рисовать
        затем нам надо реализовать самому класс панели наследываный от JPanel и реализовать метод paintComponent
        в метод paintComponent надо добавить такие строки:
        if(scene!= null) {
            for (GameMode.Drawable drawable : scene.getDrawObjects()) {
                drawable.draw(g);
            }
        }
        также нам надо ссоздать перемную scene и добавить туда ссылку на объект класса GameMode.Scene в котором и находиться наша
        панель

        сделать с помощю метода addDrawable((сюда мы просто передаем ссылку на объек который
        хоти рисовать))
